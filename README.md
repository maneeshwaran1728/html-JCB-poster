## 🚜 JCB Promotional Poster Website

### 🎨 Interactive JCB Poster

A visually engaging **JCB promotional poster website** developed using **HTML, CSS, and JavaScript**. The project focuses on creating an attractive digital poster with a modern layout, construction-themed design, and interactive elements.

### ✨ Features

- 🚜 JCB-themed promotional design
- 🎨 Modern and attractive UI
- 📱 Responsive layout
- ⚡ JavaScript interactions
- 🖼️ High-quality visual presentation
- ✨ Smooth animations and effects
- 📐 Structured and clean layout
- 💻 Desktop and mobile friendly
